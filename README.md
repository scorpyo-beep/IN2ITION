# IN2ITION

**Think it. Type it. Reveal it.**

This is the first playable mobile PWA prototype for IN2ITION.

## Included
- Numbers, Colours, Animals
- Random as the final challenge
- Easy / Medium / Hard
- Typed guesses
- Picture/emoji reveal
- Points
- Timed scores
- Local points/time leaderboards
- Achievement collection
- Category trophies
- Particle-burst trophy animation
- Glowing badges
- Daily and weekly challenge screens
- Dark/light/ocean themes
- Sound toggle
- Local progress saving
- Offline/PWA support

## GitHub Pages
1. Create a repository named IN2ITION.
2. Upload everything in this folder.
3. GitHub → Settings → Pages.
4. Deploy from the main branch and root folder.
5. Open the Pages address on your Android phone.
6. Browser menu → Add to Home screen / Install app.
